**Detailed Notes: Driver Drowsiness Detection System**

This program uses **computer vision** to detect if a driver is getting drowsy by monitoring **Eye Aspect Ratio (EAR)** in real-time using a webcam.

---

### **1. Imports**

```python
import cv2
import time
import math
import mediapipe as mp
from mediapipe.python.solutions import face_mesh
import numpy as np
```

- **`cv2`**: OpenCV — for video capture, image processing, and drawing on frames.
- **`time`**: To calculate FPS and manage timing.
- **`math`**: For Euclidean distance calculation.
- **`mediapipe as mp`**: Google’s MediaPipe — provides high-accuracy face landmark detection.
- **`face_mesh`**: Specific solution from MediaPipe for detecting 468 facial landmarks.
- **`numpy as np`**: (Imported but not heavily used here — good practice for potential future extensions).

### **3. Configuration Constants**

```python
EYE_AR_THRESH = 0.21
EYE_AR_CONSEC_FRAMES = 20
```

- **`EYE_AR_THRESH = 0.21`**: If EAR falls **below 0.21**, eyes are considered closed.
- **`EYE_AR_CONSEC_FRAMES = 20`**: Eyes must stay closed for **20 consecutive frames** before triggering alarm (avoids false positives from blinking).

```python
LEFT_EYE = [33, 160, 158, 133, 153, 144]
RIGHT_EYE = [362, 385, 387, 263, 373, 380]
```

- Indices of **6 key landmarks** for each eye in MediaPipe’s Face Mesh model.
- These points represent the eye contour used to compute EAR.

### **4. Helper Functions**

#### **a. Euclidean Distance**

```python
def euclidean_distance(p1, p2):
    return math.sqrt((p1[0] - p2[0]) ** 2 + (p1[1] - p2[1]) ** 2)
```

- Calculates straight-line distance between two points `(x1,y1)` and `(x2,y2)`.

#### **b. Eye Aspect Ratio (EAR)**

```python
def eye_aspect_ratio(eye_points):
    A = euclidean_distance(eye_points[1], eye_points[5])
    B = euclidean_distance(eye_points[2], eye_points[4])
    C = euclidean_distance(eye_points[0], eye_points[3])
    ear = (A + B) / (2.0 * C)
    return ear
```

**Formula**:  
$$
EAR = \frac{||p2-p6|| + ||p3-p5||}{2 \times ||p1-p4||}
$$

- Vertical distances (A, B) vs horizontal distance (C).
- When eyes are open → EAR is higher (~0.3+).
- When eyes are closed → EAR drops significantly (< 0.21).

#### **c. Landmark to Pixel Coordinates**

```python
def landmark_to_point(landmark, width, height):
    return int(landmark.x * width), int(landmark.y * height)
```

- MediaPipe returns normalized coordinates (0.0 to 1.0).
- This converts them to actual pixel positions on the frame.

#### **d. Get Eye Points**

```python
def get_eye_points(landmarks, eye_indices, width, height):
    points = []
    for idx in eye_indices:
        points.append(landmark_to_point(landmarks[idx], width, height))
    return points
```

- Extracts the 6 points for left or right eye.

### **5. Main Function – Core Logic**

#### **Video Capture Setup**

```python
cap = cv2.VideoCapture(0)
```

- Opens the default webcam.

#### **FaceMesh Initialization**

```python
with mp_face_mesh.FaceMesh(
    static_image_mode=False,
    max_num_faces=1,
    refine_landmarks=True,
    min_detection_confidence=0.5,
    min_tracking_confidence=0.5
) as face_mesh:
```

- `static_image_mode=False`: Optimized for video (uses tracking).
- `refine_landmarks=True`: Better accuracy around eyes and lips.
- `max_num_faces=1`: We only care about one person (the driver).

#### **Main Loop**

```python
while True:
    ret, frame = cap.read()
    frame = cv2.flip(frame, 1)        # Mirror image (natural feel)
```

---

### **Processing Each Frame**

1. **Convert to RGB** (MediaPipe expects RGB):
   ```python
   rgb_frame = cv2.cvtColor(frame, cv2.COLOR_BGR2RGB)
   ```

2. **Face Landmark Detection**:
   ```python
   result = face_mesh.process(rgb_frame)
   ```

3. **If Face Detected**:
   - Extract landmarks.
   - Get left and right eye points.
   - Calculate EAR for both eyes and take average.

4. **Drowsiness Logic**:
   ```python
   if ear < EYE_AR_THRESH:
       counter += 1
       if counter >= EYE_AR_CONSEC_FRAMES:
           drowsy = True
           play_alarm()
           # Show alert
   else:
       counter = 0
       drowsy = False
   ```

### **Key Concepts Explained**

| Concept               | Purpose |
|----------------------|--------|
| **EAR**              | Non-intrusive way to measure eye closure without training complex ML models |
| **Consecutive Frames** | Prevents false alarms from normal blinking |
| **Landmark Detection** | MediaPipe is fast and accurate for real-time use |
| **Frame Mirroring**   | Makes the experience feel natural (like looking in a mirror) |
